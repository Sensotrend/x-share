About this demonstrator

SMART Health Links (SHL) let a person share health information with a link or QR code. When the link is created, the data is encrypted. The decryption key is carried inside the link itself, so the server that stores the data can't read the stored copy.

The xShare Yellow Button envisions everyone sharing their health data in the European Electronic Health Record Exchange Format (EEHRxF) with one click. This utility shows one way the Yellow Button could work: choose a document, choose how to share it, and hand the resulting QR code to a clinician, family member or app.

What a link contains

  • url: where the encrypted data can be fetched (the "manifest")
  • key: the 256-bit decryption key
  • exp, label, flag: optional information shown to the receiver (P = passcode required, L = long-term)

Managing links

When a link is created, the server returns a management token. This app keeps it in your browser so you can see when and by whom a link was opened, and revoke the link when it is no longer needed.
